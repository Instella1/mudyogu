# 「원시인록 여행기」 개발 인수인계

## 1. 클로드에게 전달할 요청

이 문서와 함께 제공한 `primal-journey.html`이 현재 최신 원본이다. **새로 만들거나 재디자인하지 말고 이 파일을 읽고 이어서 수정**해 달라. 단일 HTML 오프라인 Canvas 액션 게임이다. 사용자와 확정한 현재 설정은 아래와 같다. 문서보다 실제 코드가 세부 구현의 기준이며, 불일치가 있으면 사용자에게 확인하라. 다음 기능 요청은 아직 없다. 먼저 구조와 검사를 파악하고 이후 요청을 받아 작업하면 된다.

## 2. 사용자가 중요하게 여기는 방향

- 게임명: **원시인록 여행기**, 주인공: 창을 쓰는 원시인 **인록**. 현재 외형은 **머리카락·머리띠 없는 삭발**이다.
- 모티브는 **할로우 나이트 같은 탐험형 횡스크롤 액션**. 원작의 그래픽/캐릭터를 복제하는 것은 아니다.
- 친구들이 플레이할 게임이지, 친구들과 함께하는 멀티플레이 게임이 아니다.
- **스테이지 선택 화면을 일반 메뉴로 다시 넣지 말 것.** 보스를 쓰러뜨린 뒤 직접 오른쪽으로 걸어 다음 지역에 도착한다.
- 시작 화면은 분위기 있는 동굴 배경·제목·간결한 메뉴. 기록 대시보드, 보스 미리보기, 복잡한 조작 설명을 처음부터 노출하지 않는다.
- 일반 몹은 **아직 없음**. 사용자가 나중에 요청할 예정이라고 했다. 연결 통로와 접근 구간을 유지하고 임의로 몹을 추가하지 않는다.
- 보스 체력은 막대만 표시하고 실제 HP 숫자는 노출하지 않는다.
- 프테라노돈은 **거대한 괴물이 공중에서 주인공을 사냥하는 체감**이 중요하다. 제자리 왕복, 정해진 지점으로 순간이동, 잦은 강제 이륙으로 되돌리지 않는다.
- 사용자 요청 외의 밸런스를 함부로 바꾸지 않는다. 변경한 게임 파일을 실제로 전달해야 한다.

## 3. 실행과 파일

- `primal-journey.html`: 최신 전체 게임. 외부 라이브러리·이미지·폰트 없이 HTML/CSS/JS가 한 파일에 들어 있다.
- 브라우저에서 파일을 열어 실행하거나 정적 웹 호스팅에 올린다. 빌드와 패키지 설치 불필요.
- Canvas 내부 해상도 1280×720, 반응형 16:9. 데스크톱 키보드와 터치 버튼 지원.
- JS는 즉시 실행 함수 내부. 개발 훅은 `window.primalJourney`에 노출.
- 실행 환경에 따라 로컬 파일의 저장 동작이 다를 수 있다. 안정적인 저장 비교에는 동일 브라우저·동일 출처의 정적 서버 사용 권장.
- 함께 제공한 검사는 Node.js 내장 `fs`, `vm`, `assert`만 사용한다.
- 원래 사용자 전달 파일명은 `원시인록-여행기.html`이었다. 묶음 안의 영문 파일이 바로 그 최신 소스다.

## 4. 기본 조작 및 주인공

| 조작 | 기본키 |
|---|---|
| 좌우 이동 | A / D |
| 점프·더블점프 | W |
| 발판 아래로 내려가기 | S (지면은 뚫지 않음) |
| 일반 공격 | J |
| 무적 회피 | K |
| 창 던지기 | L |
| 재도전 | R |
| 일시정지 | Esc |
| 디버그 패널 | F2 |

- 체력 **6칸**, 일반 이동속도 **290**, 회피속도 **850**, 회피시간 **0.17초**, 재사용 **0.7초**.
- 일반 창 공격 **10 피해**, 공격 간격 **0.3초**. 점프 초기속도 -600, 더블점프 -550.
- 창 던지기는 포물선으로 날아가 적을 관통하고 **각 적에게 60 피해 1회**. 던진 창을 회수하기 전에는 일반 공격·재투척 불가.
- 땅/발판/접근 가능한 창 근처에서 자동 회수. 맵 끝 벽에 박히면 **3초 뒤 떨어짐**. 기존 보스 무적 방어는 유지.
- 키 설정 변경·중복 키 교환·기본키 복원 지원. 이전 기본 배치는 JKL로 자동 이관하되 명시적으로 바꾼 사용자 설정은 보존.
- 시작 컷신: 추락→착지→주변 탐색→창 발견·획득. 약 13.5초, Enter/버튼으로 생략. 재도전은 컷신 생략.
- 소리 기본 꺼짐. 합성 음향 사용.

## 5. 지역·진행·기록·메뉴

1. **잊힌 뿔의 계곡**: 트리케라톱스
2. **울림의 동굴**: 랩터 두 마리
3. **바람의 하늘 절벽**: 프테라노돈

- 각 지역에 접근 통로·모닥불 체크포인트·보스전이 있다.
- 승리 결과에서 ‘여행 계속하기’를 누르면 클리어된 필드로 돌아오며, 오른쪽 길로 직접 다음 지역에 간다. 단순 ‘다음 스테이지 버튼’으로 바꾸지 않는다.
- 3지역 뒤는 현재 여행의 끝인 조용한 길. 4지역은 없음.
- 이어하기는 저장된 지역/체크포인트 기준. 진행 중인 보스전의 실시간 HP까지 저장하는 방식이 아니다.
- 홈 버튼은 **홈으로 돌아가기/취소만 있는 독립 확인창**. 설정창을 띄우지 않는다. 취소/Esc로 이전 상태 복귀.
- 설정·홈 확인·일시정지·디버그에서 게임 정지.
- 별점: 남은 체력 **6→5개, 5→4개, 4→3개, 3→2개, 1~2→1개**.
- 지역별 총 클리어·최고 별점·최단 시간·최근 10회(시간/체력/별점)를 저장.
- ‘여행 기록’에서 **미클리어 지역의 지역명·별점·정보는 모두 `???`**, 상세 내역 숨김. 첫 클리어 후 공개. 미래 지역도 이 규칙을 따른다.
- 새 여행은 진행을 새로 시작하지만 기존 최고 기록은 지우지 않는다.

### 저장 키와 호환성

- `primalJourney.keys.v2`: 키 배치
- `primalJourney.records.v1`: 과거 1지역 기록, 호환 유지
- `primalJourney.records.v2`: 지역별 기록
- `primalJourney.progress.v1`: 여정 진행
- 예전 진행에는 `cleared[3]`가 없을 수 있고, 2지역의 옛 `ending`은 현재 `passage`로 이관한다. 저장 검증과 이관을 없애지 않는다.
- 저장 차단/손상된 JSON에도 게임은 동작하며 안내를 띄운다.

## 6. 1지역 트리케라톱스 (유지할 수치)

- HP **1080**, 2페이즈 **720 이하**, 3페이즈 **360 이하**.
- 일반 이동속도 **62 / 82 / 158**.
- 1페이즈: 1초 예고 후 속도 **1080** 돌진. 9초마다 1초 무적 방어.
- 2페이즈: 두발 로봇, 높이 98→196. 엎드린 돌진속도 **940**. 방어 유지.
- 3페이즈: 일반 이동 증가, 방어 없음. 엎드린 돌진속도 **1200**.
- 2·3페이즈 돌진 예약 주기 **7초**, 예고 0.75초, 돌진 0.95초. 다른 상태 때문에 실제 발동이 늦어질 수 있음.
- 돌진 종료 **2초 뒤** 눈 레이저, 총 2.2초, 최초 0.45초 예고, 추적 각속도 **0.28 rad/s**.
- 로봇 접촉 발차기 **2 피해**, 넉백 가로 1000 / 세로 -480, 경직 0.62초. 레이저/일반 접촉 1 피해.
- 가만히 있는 플레이어에게도 추격·접촉이 닿는 회귀 검사 존재.

## 7. 2지역 랩터 (현재 확정)

- 작은 체구, 첫 랩터 HP **800**.
- 1페이즈 기본속도 **140**, **10초마다** 점프.
- 첫 랩터 HP **500 이하**: 하늘 향한 울음(1.6초) 후 벽에서 둘째 랩터 HP **500** 등장. 두 마리 기본속도 **190**.
- 둘 중 살아 있는 랩터 하나가 HP **150 이하**: 살아 있는 둘 모두 로봇 강화, 기본속도 **240**.
- 3페이즈: 각자 **5초 주기**, 두 마리 발동을 **2.5초 차이**(첫 예약 5 / 7.5)로 엇갈리게 함. 점프 후 구르기 **속도 320 / 2.5초**.
- 구르기는 벽까지 직진하지 않고 **현재 플레이어 위치를 계속 따라 방향 전환**. 플레이어를 지나쳐 벽으로 가는 구패턴으로 되돌리지 말 것.
- 구르는 동안만 받는 피해 **절반**: 일반 5 / 창 30. 나머지 상태 일반 10 / 창 60.
- 점프 준비 중에도 전진, 공중에서도 가로 이동. 점프 초기 -1550, 상승 중 중력6500 / 하강11000. 검사상 높이 약184, 체공 약0.422초(측정 간격에 따라 차이).
- 두 번째 랩터 체력바는 처음엔 완전히 숨기고 등장 후 약0.7초 동안 나타나며 차오름.
- 두 마리 모두 죽어야 승리. 첫 랩터를 빨리 죽여도 둘째 소환이 생략되면 안 됨.

### 치고 빠지기 · 협공 (2026-10-27 추가, 사용자 확정)
- 걷기(`walk`)는 플레이어에게 붙지 않는 **간보기**: 약 200px 거리에서 어슬렁거림. 멀면 기존 속도(140/190/240)로 접근.
- **물기**: 240px 안에서 0.4초 예고(웅크림·붉은 눈·붉은 막대) → 0.18초 돌진(최대 170, 플레이어 앞 20px에서 멈춤) → 0.5초 빈틈(제자리) → 0.35초 뒤로 150 폴짝 후퇴. 물기 피해1, 회피/무적 존중.
- **접촉 피해1은 모든 상태에서 항상 유지** (사용자 지시. 물 때만 피해로 바꾸지 말 것).
- **협공**(두 마리): `packLead` 미끼는 지금 쪽에서 간보기, 다른 하나는 사냥꾼으로 플레이어 반대편을 노림. 같은 쪽이면 0.35초 예고 후 머리 위로 0.7초 도약(높이210)해 반대편 170 지점에 착지. 반대편 착지 공간이 없으면 미끼 뒤에서 대기.
- **번갈아 물기**: 동시에 물지 않음. 물기 후 1.1초(혼자면 1.4초) 대기, 이어서 1.5초 동안은 다른 랩터에게 차례 우선.
- **교차 도약**: 약 8초마다 둘이 양쪽에 있고 조건이 맞으면 동시에 머리 위로 자리를 바꾸고 미끼/사냥꾼 교대.
- 3페이즈: 누가 구르는(`rollTell/rollJump/roll`) 동안 다른 랩터는 물기·도약 안 함.
- 정해진 점프(10초)·구르기(5초, 2.5초 엇갈림) 예약은 절대 밀리지 않음: 예약까지 물기는 1.6초, 도약은 1.2초 이상 남았을 때만 시작.
- 수치는 `RAPTOR` 상수, 로직은 `packPlan`, `raptorCanAct`, `tryPackSwap`, `packAfterBite`, `biteRect`.
- 접촉 피해1. 창은 두 마리에 각각60, 공격별·투사체별 중복 타격 방지.

## 8. 3지역 프테라노돈 (특히 최신 상태 주의)

### 체력·공간
- **최대 HP1100 / 2페이즈 HP700 이하 / 3페이즈 HP400 이하**. 최신 요청으로 확정됨. 이전 900/580/250은 폐기.
- 매우 큰 체구. 날개는 한 차례 약18% 줄였고 이후 몸통·머리를 키웠다. 인록과 비교해 거대한 공중 포식자여야 한다.
- 양쪽에 하나씩, 더블점프로 올라갈 수 있는 전투용 발판. S로 내려감. 창도 발판에 떨어지고 회수 가능.

### 기본 행동
- 정해진 중심점의 사인 왕복이 아니라 **실제 플레이어 위치를 쫓는 가속·관성 기반 비행**. 머리 위를 지나며 선회, 부드러운 방향 전환·뱅킹. 발판 높이에 반응하며 이륙 목표도 플레이어 기준.
- 약 **4초 비행 → 0.6초 예고/타깃 고정 → 0.50초 급강하**.
- 급강하 중 실제 입에 잡히면 **즉사**. 몸통·날개에 닿았다고 즉사시키지 않는다. 회피/피격 무적은 존중.
- 빗나가면 지면에 **2초 박힘 → 7.5초 지상 추격/공격 → 2초 점진 이륙**.
- 지상 걷기속도 **220**, 부리 돌진 최대 **150**을 **0.20초**에 이동, 0.45초 예고, 2초 단위 공격. 지상 공격1 피해, 즉사 아님.
- **위치 순간이동 금지**: 착륙 끝, 이륙 시작, 특수 공격 이동/복귀가 모두 연결되어야 함.
- 동적 날갯짓·몸 기울기·고도별 바닥 그림자·낮은 고도 바람 먼지가 구현됨.

### 2페이즈 추가 — 메테오 폭우 (현재 패턴)
- 로봇 강화. **전방 부채꼴 초음파는 완전히 폐기**했다.
- 하늘 향한 약 **0.75초 포효**로 메테오 소환 → 이륙/정상 행동 복귀.
- 독립 이벤트로 **10초 동안 정확히30개** 생성. 약 1/3초 간격.
- 18개는 플레이어 위치/속도 예측, 12개는 전장 분산 배치. 발판도 위협.
- 예고 0.16~0.20초, 낙하 0.22~0.28초, 착탄 반경40 / 잔류0.15초. 피해1, 회피/무적 존중. 빠른 낙하 관통 방지용 선분 충돌 사용.
- **메테오 중에도 보스가 정상 추격·급강하·지상 공격·레이저를 계속한다.** 10초 대기 상태로 만들지 말 것.
- 보스는 메테오 피해 없음. 진행 중 이벤트 재호출로 타이머를 리셋/연장하지 않는다.
- 리셋·지역 이동·디버그 페이즈 변경·승리·홈 복귀에서 잔여 메테오 정리. 메뉴 정지 중 이벤트도 정지.

### 3페이즈 추가 — 파란 레이저
- 가장자리 발사 위치로 **2초에 걸쳐 이동**, 1초 예고.
- 입에서 반대편 맵 끝까지 수평 파란 레이저, 피해1.
- 발사한 채 **6초 동안 낮은 곳→높은 곳→낮은 곳** 왕복 비행. 단순히 한 번 상승만 하는 옛 구현은 폐기.
- 빔은 실제 입 위치를 연속 추적. 몸체가 화면 밖으로 크게 잘리지 않도록 안쪽에 배치하고 날개를 접는 자세 사용.
- 메테오와 레이저가 겹칠 수 있음. 기존 급강하/지상 패턴도 사라지지 않아야 함.

## 9. 디버그

- 게임 중 F2 또는 디버그 버튼. 열린 동안 정지. F2/Esc 닫기.
- 지역1 트리케라톱스 / 지역2 랩터 / 지역3 프테라노돈을 **진행도와 관계없이 자유 선택**. 새 지역 전투장에 체력 회복 상태로 바로 배치.
- 각 보스 1·2·3페이즈 직접 선택. 랩터 둘째 소환·로봇화·엇갈린 예약까지 적용.
- 패널만 열고 닫는 것은 정상 기록에 영향 없음.
- **지역/페이즈를 실제 변경한 여정은 기록·진행 저장에서 제외**. 닫거나 재도전해도 테스트 표시는 유지. 홈 복귀 시 디버그 이전 정상 진행 스냅샷 복원. 새 여행/정상 이어하기에서 테스트 종료.
- 디버그로 정상 저장을 덮어쓰거나 클리어 기록을 부풀리는 회귀를 주의.

## 10. 코드 탐색 지점

HTML 내 함수/상수 이름으로 검색하면 된다(줄번호는 수정 시 달라짐).

- `defaults`, `bindings`, `refreshControls`, `assignKey`: 키 설정
- `loadProgress`, `validProgress`, `saveProgress`, `enterRegion`, `restoreProgress`, `continueJourney`, `markCleared`: 여정
- `stageRecords`, `renderRecords`, `renderSkyRecords`, `recordClear`, `clearStarsFor`: 기록
- `reset`, `update`, `updatePlayer`, `render`: 주 루프
- `updateBoss`: 지역별 보스 업데이트 분기
- `RAPTOR`, `makeRaptor`, `checkRaptorPhases`, `damageRaptor`, `updateRaptors`, `drawRaptor`
- `PTERA`, `makePtera`, `checkPteraPhases`, `updatePtera`, `pteraSpecial`, `pteraTakeoff`, `drawPtera`
- `pteraMouth`, `pteraBodyRect`, `pteraContacts`, `hurtPtera`: 외형/입/충돌整合에 주의
- `beginMeteorEvent`, `spawnMeteor`, `advanceMeteors`, `updateMeteors`, `drawMeteors`, `clearMeteors`
- `throwSpear`, `updateSpear`, `drawSpear`: 창
- `toggleDebug`, `debugPhase`, `debugStage`, `debugSnapshot`, `discardDebugJourney`

### 브라우저 개발 훅
```js
const g = window.primalJourney;
g.start();                   // 정규 새 여행
g.finishIntro();
g.toggleDebug();
g.debugStage(3);             // 테스트 전용 지역 바로 이동
g.debugPhase(2);
g.closeDebug();
g.getState();                // 복사된 상태/메테오 요약 포함
g.previewStage3(2,'meteor');  // 테스트 표시가 붙는 패턴 미리보기
g.previewStage3(3,'laser');
g.step(1 / 60);
g.render();
```
`startStage()` / `startStage3()`는 개발 훅이다. 정상 저장 보호가 필요한 테스트에는 디버그 경로를 권장한다. 반환 객체의 복사본을 수정해도 내부 상태 변경을 보장하지 않으므로 테스트 파일의 vm 주입 방식을 참고하라.

## 11. 검사·검증

같은 폴더에서 실행:
```sh
node test-balance.cjs
node test-raptor.cjs
node test-journey.cjs
node test-debug.cjs
node test-ptera.cjs
```

마지막 개발 시 보고된 결과: **151개 통과**(밸런스31 + 랩터44 + 여정10 + 디버그13 + 프테라노돈53). 인수인계 시 다시 실행한 결과는 `검사결과.txt` 참고.

- DOM/Canvas/localStorage를 모의한 Node vm 회귀 검사. 실제 브라우저 플레이 품질을 완전히 보장하지 않는다.
- 프테라노돈 자연 반복 궤적은 고정 간격으로 검사하며 순간이동 회귀 방지, 예측 추격, 입 충돌, 메테오 정확30개, 동시 AI, 저장 보호 등이 검사 대상.
- 게임 디자인 품질은 수치 검사만으로 판정하지 말고 **실제 브라우저에서 조작하며 확인**할 것. 특히 거대 보스 추격 체감, 판정과 외형 일치, 반응 가능한 예고, 발판 위 플레이를 확인.
- 구 `test-primal.cjs`는 오래된 HP12 등을 기대하는 폐기 검사라 포함하지 않았다. 미리보기 HTML 사본 역시 오래된 수치가 섞일 수 있어 포함하지 않았다.
- 포함된 `preview-ptera.cjs`, `preview-meteor.cjs`, `preview-debug.cjs`는 최신 원본으로 정지 미리보기 사본을 생성한다. 결과 파일을 원본으로 착각하지 않는다. 움직임은 정지 이미지로 검증할 수 없다.

## 12. 작업 시 금지할 회귀 및 마지막 상태

- 기본키를 Space/Shift/F로 돌리지 말 것. WASD+JKL 유지.
- 인록 머리카락·머리띠를 되살리지 말 것.
- 여행 기록에 미클리어 이름/보스 스포일러 노출 금지.
- 일반 타이틀에 스테이지 선택 버튼 재도입 금지(디버그에는 허용).
- 프테라노돈을 고정 지점으로 순간이동시키거나 메테오 동안 멈추게 하지 말 것.
- 현재 메테오는 옛 초음파 ‘범위 확대’ 상태가 아니라 **전혀 다른 소환형 공격**이다.
- 요청한 것은 지금까지 결과의 인수인계이며, 이 시점에 미완료로 약속된 다음 기능은 없다. 사용자의 다음 지시를 받아 이어간다.
